# sync-gitee

Obsidian 插件 — 端到端加密同步笔记到 Gitee 仓库。

## 特性

- **端到端加密**：AES-256-GCM 加密，本地明文，远程密文
- **全平台**：支持桌面端和移动端（iOS/Android）
- **二进制文件**：支持图片、PDF 等文件类型
- **密码保护**：密码变更检测，防止数据无法解密
- **文件级加密**：不同文件夹使用不同密码

### 同步体验

| 功能 | 说明 |
|------|------|
| **增量推送** | 本地修改后自动增量推送到 Gitee |
| **增量拉取** | 从 Gitee 拉取远程变更到本地 |
| **删除同步** | 本地删除文件 → 自动删除远程对应文件 |
| **保存自动推送** | 文件保存后 2 秒防抖自动推送 |
| **启动时拉取** | Obsidian 启动时自动拉取最新文件 |
| **定时同步** | 设置间隔后台自动推送 |
| **选择性同步** | 文件夹级别开关，只同步勾选的文件夹 |
| **重命名检测** | 检测文件重命名，自动更新路径映射 |

### 数据与监控

| 功能 | 说明 |
|------|------|
| **状态栏进度条** | 显示同步状态和上次同步时间 |
| **同步状态标记** | 打开文件时状态栏显示同步状态 |
| **操作历史面板** | 记录每次同步的详情 |
| **统计仪表盘** | 推送/拉取次数、文件数统计 |
| **日志导出** | 导出同步历史为 Markdown 文件 |

### 运维工具

| 功能 | 说明 |
|------|------|
| **网络诊断** | 一键测试 DNS 解析、API 连通性、令牌有效性 |
| **健康检查** | 验证远程文件完整性和密码匹配 |
| **密码提示** | 设置密码提示帮助记忆 |
| **测试连接** | 验证 Gitee 令牌和仓库配置 |

### AI 集成

| 功能 | 说明 |
|------|------|
| **内嵌 MCP 服务器** | 启动本地 MCP 服务器（端口 3100），AI 客户端可直接读取 vault 文件 |
| **list_notes** | 列出 vault 中所有笔记 |
| **read_note** | 按路径读取笔记内容 |
| **search_notes** | 按关键词搜索笔记内容 |

## 安装

1. 在 Obsidian 设置中启用 Community 插件
2. 从 Releases 下载 `main.js`、`manifest.json`、`styles.css`
3. 复制到 `<vault>/.obsidian/plugins/sync-gitee/`
4. 启用插件并填写配置

## 配置

| 设置项 | 说明 |
|--------|------|
| Gitee 用户名 | 仓库所有者的用户名 |
| 仓库名称 | Gitee 仓库名称 |
| 访问令牌 | Gitee 个人访问令牌（需 repo 权限） |
| 加密密码 | 用于端到端加密的密码 |
| 密码提示 | 帮助记忆密码的提示 |
| 文件夹加密密码 | JSON 格式，不同文件夹使用不同密码 |
| 分支 | 推送的目标分支（默认 master） |
| 忽略模式 | 逗号分隔的路径前缀，匹配的文件不会推送 |
| 同步文件夹 | 逗号分隔的文件夹路径，留空则同步所有 |
| 最大文件大小 | 超过此大小的文件将被跳过 |
| 保存后自动推送 | 开启后文件保存自动推送 |
| 启动时自动拉取 | 开启后 Obsidian 启动时自动拉取 |
| 定时同步间隔 | 设置分钟数，后台自动推送 |
| MCP 服务器 | 开启后启动本地 MCP 服务器（桌面端） |

## 使用

- **推送全部文件**：点击 Ribbon 图标或运行命令
- **从 Gitee 拉取全部**：Ribbon 菜单 → 从 Gitee 拉取全部
- **选择文件推送**：Ribbon 菜单 → 选择文件推送
- **右键推送/拉取**：在文件上右键 → 推送至 Gitee / 从 Gitee 拉取
- **查看历史**：设置 → 同步历史
- **MCP 连接**：AI 客户端连接 `http://localhost:3100`

## 加密格式

```
格式: GSE1:<base64>
Base64 解码后 = salt(16) + iv(12) + encryptedData + authTag
```
